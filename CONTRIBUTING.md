# Contributing to HoloDocchi

Thank you for your interest in HoloDocchi.

HoloDocchi is an unofficial fan project. Contributions should preserve the
project's separation between public product behavior, public data, and
third-party content.

## Good contribution areas

Contributions are welcome for areas such as:

- accessibility and usability improvements;
- responsive/mobile UI improvements;
- bug fixes;
- localization and wording corrections;
- documentation;
- data-schema validation;
- search and discovery improvements;
- test coverage;
- performance improvements that preserve user-visible behavior.

## Before submitting a change

Please keep the following principles in mind:

1. Do not commit credentials, cookies, tokens, private databases, or personal data.
2. Do not treat third-party content as project-owned content.
3. Preserve the separation between unrelated data domains where possible.
4. Avoid introducing a new dependency on a dynamic backend when static publication is sufficient.
5. Keep externally sourced data attributable and reviewable.
6. Describe user-visible behavior changes clearly in the pull request.
7. For data-related changes, explain the source and the intended public use.

## Pull requests

A useful pull request should explain:

- what problem it solves;
- which HoloDocchi feature is affected;
- whether user-visible behavior changes;
- whether public data or third-party content is involved;
- what was tested or reviewed.

Small, focused changes are generally easier to review than unrelated changes
combined into one pull request.
