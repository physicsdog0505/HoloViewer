# Security Policy

HoloDocchi is a public fan project. Security reports should focus on issues
that could affect users of the public HoloDocchi service or expose information
that should not be public.

## Please report

Examples include:

- exposed credentials or secrets;
- unintended access to non-public data;
- cross-site scripting or injection vulnerabilities;
- unsafe handling of external URLs or embedded content;
- vulnerabilities that could affect other HoloDocchi users;
- accidental exposure of personal information.

## Do not publish sensitive details

If a report includes a working exploit, credential, token, private data, or
other sensitive material, do **not** place those details in a public issue.

Use GitHub's private security-reporting mechanisms when available.

For non-sensitive bugs that do not create a security risk, a normal GitHub
issue is appropriate.

## Scope

This policy applies to the public HoloDocchi project and public-facing service.

Third-party platforms such as YouTube, Google, PTT, Cloudflare, COVER Corp.,
and hololive production have their own security and reporting processes.
Issues that belong entirely to those services should be reported to the
relevant provider.

## Responsible handling

Please provide enough information to understand the affected HoloDocchi
behavior without including unrelated personal information or secrets.
